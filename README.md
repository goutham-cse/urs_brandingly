# Brandingly website

A responsive, dependency-free multi-page website for the Brandingly Creative Agency.

## Pages

- `index.html` — home
- `who-we-are.html` — agency story and values
- `what-we-do.html` — approach
- `services.html` — services and featured Chennai partners
- `contact.html` — enquiry form

Open `index.html` in a browser to preview the site. The shared styles, animation behavior, and supplied visual assets live in `styles.css`, `script.js`, and `assets/`.

The contact form posts to FormSubmit for delivery to `ursbrandingly@gmail.com`. FormSubmit may send a one-time verification email to that address the first time the form is used; confirm it to enable delivery.
